Notes
-----
- app.py also creates and uses additional admin/system-related tables dynamically.
- To export the actual inserted data, start XAMPP MySQL first and then dump the
  database `trading_app`.

Suggested Export Command
------------------------
mysqldump -u root trading_app > trading_app_backup.sql

If MySQL has a password, use:
mysqldump -u root -p trading_app > trading_app_backup.sql
